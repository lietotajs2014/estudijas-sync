# estudijas-sync — privātuma politika / Privacy policy

**Latviski.** estudijas-sync ir programma, kas darbojas tikai lietotāja paša datorā. Tā nolasa lietotāja RTU estudiju (estudijas.rtu.lv) kursus un termiņus. Ja lietotājs to ieslēdz, programma izveido un atjaunina notikumus atsevišķā Google kalendārā "RTU estudijas" lietotāja paša Google kontā.

- Dati netiek sūtīti nevienam serverim, izņemot estudijas.rtu.lv un Google Calendar API pēc lietotāja pieprasījuma.
- Google piekļuves atslēga glabājas tikai lietotāja datorā (`~/.estudijas_sync/<profils>/google_token.json`). To var atsaukt jebkurā brīdī: https://myaccount.google.com/permissions.
- Programma piekļūst tikai kalendāriem, lai izveidotu un atjauninātu termiņu notikumus. Citus Google datus tā nelasa.
- Dati netiek pārdoti, kopīgoti ar trešajām pusēm vai izmantoti reklāmai.

**English.** estudijas-sync is a desktop tool that runs only on the user's own computer. It reads the user's own RTU e-studies (Moodle) courses and deadlines. When enabled by the user, it creates and updates events in a separate "RTU estudijas" calendar in the user's own Google account.

- No data is sent to any server other than estudijas.rtu.lv and, at the user's request, the Google Calendar API.
- The Google access token is stored only on the user's computer and can be revoked at any time at https://myaccount.google.com/permissions.
- The app uses Google Calendar access solely to create and update deadline events. It does not read other Google data.
- No data is sold, shared with third parties, or used for advertising.
