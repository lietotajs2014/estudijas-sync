Pieslēdz e-studijas

Lapai vajag to pašu piekļuvi, ko izmanto oficiālā Moodle lietotne (mobilās lietotnes žetons). Tava RTU parole šeit netiek ievadīta.

1. variants: drošības atslēga

  1. Atver e-studijas → Preferences → Security keys (piesakies kā parasti, ar MFA).
  2. Atrodi rindu Moodle mobile web service un nokopē atslēgu (32 simboli).
  3. Ielīmē to zemāk.

Ja šīs rindas nav, vienreiz piesakies oficiālajā Moodle lietotnē telefonā un atver lapu vēlreiz, vai izmanto 2. variantu.

2. variants: lietotnes saite (sarežģītāk)
  1. Esot pieteicies e-studijās, atver datorā pārlūka DevTools (F12) → Network.
  2. Atver šo saiti. Pārlūks mēģinās atvērt moodlemobile://….
  3. Network sarakstā atrodi launch.php → Response headers → location un nokopē visu vērtību, kas sākas ar moodlemobile://token=.

Žetons tiek glabāts šifrēts. To jebkurā brīdī var atsaukt e-studijās (Security keys → Reset) vai šīs lapas iestatījumos.
